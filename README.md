# Vietnam Travel Planner

## Installation
Create and active ENV

python3 -m venv venv

source venv/bin/activate

Install the required packages:

pip install -r requirements.txt


## Chạy code trên macos

Run the application:


python main.py // sử dụng bằng terminal

streamlit run app.py // sử dụng bằng Streamlit



Thực hiện theo các hướng dẫn trên màn hình để:
1. Tìm con đường ngắn nhất giữa hai địa điểm
2. Tìm tất cả các vị trí có thể tiếp cận từ điểm xuất phát
3. Tìm cây bao trùm tối thiểu từ một vị trí
4. Hình dung toàn bộ đồ thị
